## Capacity Planning

### Краткое описание:

Инструмент для тимлида студенческого проекта. 
Позволяет оценить, сколько "человеко-часов" доступно у команды на спринт (с учётом дедлайнов других предметов), 
распределить задачи и наглядно увидеть перегрузку или простой участников. 
Интегрируется с календарём академических событий.

### Цель:

Автоматизировать расчет загруженности студента одновременно и внутри проекта, и по учебе.

### Запуск проекта:

`npm start`

Запускает приложение в режиме разработки.
Откройте http://localhost:3000 для просмотра в браузере.

`npm test`

Запускает программу запуска тестов в режиме интерактивного просмотра.

`npm run build`

Создает приложение для рабочей среды в папке build.
